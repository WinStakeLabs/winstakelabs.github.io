# WinStake Labs Website

Static website for WinStake Labs - a Ukrainian-operated Solana mainnet validator.

Live: https://winstakelabs.com

## Structure

| File | Purpose |
|------|---------|
| `index.html` | Main page (English) |
| `index-ua.html` | Main page (Ukrainian) |
| `mission-en.html` | Mission page (English) |
| `mission.html` | Mission page (Ukrainian) |
| `tools.html` | Curated Solana tools hub |
| `security.html` | Security and responsibility |
| `robots.txt` | Search engine instructions |
| `sitemap.xml` | Sitemap for indexing |
| `CNAME` | GitHub Pages custom domain config |
| `winstakelabs.png/.svg` | Logo |
| `winstakelabs_w.png` | Logo on white background |
| `og-image.png` | Open Graph preview for social shares |
| `favicon.ico` | Browser tab icon |
| `vyshyvanka.svg` | Optional Ukrainian embroidery ribbon |

## Hosting

Static site, no build step, no dependencies. Open `index.html` in a browser to preview locally.

Deployed via GitHub Pages with custom domain.

Full archive of curated Solana tools: https://github.com/WinStakeLabs/solana-tools-hub
